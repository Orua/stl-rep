# 来源与授权状态 / Credits and licensing status

STL REP is a GitHub fork for the [STL replay archive](https://cnstl.cn/app/index.html#match/1/replays).

## 项目来源 / Project lineage

- **Dan Gant (`dgant`) and contributors** maintain the [direct upstream fork](https://github.com/dgant/openbw-replay-viewer) and its [browser demo](https://dgant.github.io/openbw-replay-viewer/). See the [viewer contribution history](https://github.com/dgant/openbw-replay-viewer/graphs/contributors) and [Dan's engine fork](https://github.com/dgant/openbw).
- **`bmnielsen` and contributors** maintain the [standalone replay viewer repository](https://github.com/bmnielsen/openbw-replay-viewer) from which Dan's viewer was forked. Its project history credits the [original OpenBW web replay viewer](https://www.openbw.com/replay-viewer/) and `tscmoo`'s assistance with the engine build. See the [standalone viewer contribution history](https://github.com/bmnielsen/openbw-replay-viewer/graphs/contributors).
- **Vegard Mella (`tscmoo`), `IMP-42`, `adakitesystems` and other contributors** are credited through the [OpenBW engine repository](https://github.com/OpenBW/openbw) and its [contribution history](https://github.com/OpenBW/openbw/graphs/contributors).
- **Blizzard Entertainment** created *StarCraft* and *StarCraft: Brood War*. The game data, artwork and audio are separate from the replay viewer and engine code.

## 授权状态 / Licensing status

STL 尚未获得 OpenBW 权利人就修改并公开部署原始录像播放器或随之分发 OpenBW 引擎的明确授权。我们没有在 OpenBW 上游或 Dan 的播放器仓库发现项目级许可证。上游的[许可证讨论](https://github.com/OpenBW/openbw/issues/17)仍在进行。此说明仅用于署名和记录授权状态，不授予第三方代码或游戏素材的使用许可。

STL has not obtained explicit permission from the OpenBW rights holders to modify and publicly deploy the original replay viewer or redistribute the OpenBW engine with it. We found no project-level license in the upstream OpenBW repository or in Dan's replay viewer repository. See the [upstream licensing issue](https://github.com/OpenBW/openbw/issues/17). This notice records attribution and licensing status. It grants no rights to third-party code or game assets.
