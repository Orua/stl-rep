加载暴雪游戏资源

播放录像需要《星际争霸：母巢之战》的经典画面和声音。你可以读取自己的 MPQ 文件，也可以确认从下方地址下载约 90 MB 的资源。录像文件留在浏览器内。

在线资源地址

本地模式请选择 StarDat.mpq、BrooDat.mpq 和 Patch_rt.mpq。播放重制版格式的录像时，也可同时选择 terrain.mpq。
